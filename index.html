📖 新手術語速查
ADR（美國存託憑證）
台積電在美國掛牌的憑證（代號 TSM），美股收盤後可看出台股次日開盤方向。ADR -3% ≈ 台積電次日開盤約 -80~100 元。
三大法人
外資（外國機構）＋投信（基金公司）＋自營商（券商自有資金）。三大合買越多，代表法人對後市越樂觀。
融資 / 融券
融資 = 借錢買股（看多）；融券 = 借股票賣出（放空）。融資增加表示散戶追高，過多時是警訊；融資減少反而健康。
Put/Call 比率（P/C 比）
期貨選擇權買賣比例。P/C < 0.8 表示市場偏多（買Call居多）；P/C > 1.2 表示市場偏空（買Put居多）。
RSI（相對強弱指標）
0–100，通常 > 70 為超買（短線可能回調），< 30 為超賣（短線可能反彈）。
夜盤（台指期夜盤）
台灣期貨交易所在一般交易時段結束後（15:00–05:00）提供的台指期交易。夜盤與美股同步，可預測次日開盤。
法說會（法人說明會）
公司對機構法人說明財務業績的會議。法說後若業績超預期，股價易大漲。
📚 進階術語速查
🔷 台指期未平倉量（OI）
OI 放大＋價格上漲 = 多方進場積極；OI 縮小 = 主力平倉觀望。📎 期交所 OI
🔷 大額交易人淨部位
期交所每日公佈前5大、前10大交易人多空淨部位。外資期貨多單 > 空單 = 主力看多。
🔷 均線多空排列（MA5/MA20/MA60）
MA5 > MA20 > MA60 = 多頭排列。MA5 跌穿 MA20 為「死亡交叉」，是轉弱訊號。
🔷 量縮/量增的判讀
量增價漲 = 最健康；量縮價漲 = 漲勢缺動能；量增價跌 = 賣壓沉重；量縮價跌 = 跌勢尾聲。
🔷 VIX 恐慌指數
VIX > 30 = 市場極度恐慌（反而是買點）；VIX < 15 = 過度樂觀（要小心反轉）。當前 VIX：16.91
🔷 斷頭賣壓（Margin Call）
融資戶股票下跌觸及維持率下限（通常 130%），券商強制賣出，造成集中賣壓。
🔷 NDF（無本金遠期外匯）
外資押注台幣走勢的工具。NDF 顯示外資對台幣走貶預期越強，代表未來外資流出壓力越大。
🔷 費城半導體指數（SOX）
30支主要半導體股組成，與台積電/聯發科相關性 >0.85。盤前必查。📎 Yahoo SOX
📊 市場狀態說明
💹 強勢做多
三大法人大買超 + 外資連續買超 + 大盤突破前高 + ADR 強勁上漲。可積極佈局，追高有理由。
📈 偏多
外資買超為主 + 大盤在均線之上 + ADR 微漲或持平。適合持有多單，逢回不追空。
📊 中性偏多
多空信號混雜，但偏向看多。可持有，降低倉位，等待確認信號後再加碼。
⚖️ 中性
多空力道相當，無明確方向。建議觀望或輕倉，等待盤面給出明確訊號。
⚠️ 中性偏空
有利空因素（如 ADR 下跌、外資賣超），但護盤力道尚存。降低倉位，設好停損，不追多。
⚠️ 偏空
外資轉賣超 + 大盤跌破重要支撐 + ADR 明顯下跌。宜減碼或觀望，避免逆勢操作。
🔻 強勢做空
三大法人大賣超 + 外資連續大賣 + 大盤跌破月線 + 恐慌氣氛濃厚。嚴格執行停損，保留現金。
